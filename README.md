## 🔍 Featured Case Studies

<details>
<summary><b>1. RetailIQ — Retail Analytics & Profitability Dashboard</b></summary>

<br />

* **Business Problem:** Retail managers lacked granular visibility into category-level profit margins and transactional sales velocity across store regions.
* **Technical Approach:** Processed and normalized transaction logs using Python (Pandas/NumPy) and complex SQL queries (CTEs, Window Functions). Constructed dynamic interactive workbooks in Tableau.
* **Key Outcome:** Uncovered high-margin category trends and reduced weekly inventory reporting latency by 40%.
* **GitHub Repository:** [RetailIQ Analytics Dashboard](https://github.com/piyushi-singhal/RetailIQ-Analytics-Dashboard)

</details>

<details>
<summary><b>2. MLForge — Distributed ML Model Serving & Monitoring Platform</b></summary>

<br />

* **Business Problem:** Monolithic ML prototypes caused API downtime when heavy model training jobs shared CPU/memory space with real-time inference endpoints.
* **Technical Approach:** Engineered a microservices architecture using FastAPI, RabbitMQ for job queueing, Redis for stateless prediction caching, PostgreSQL for model metadata registry, and Prometheus + Grafana for operational observability.
* **Key Outcome:** Handled over **4,200 RPS under Locust load testing** while maintaining sub-100ms p99 prediction latency and 100% async job recovery.
* **GitHub Repository:** [MLForge Platform](https://github.com/piyushi-singhal/MLForge-Distributed-ML-Model-Serving-Monitoring-Platform)

</details>

<details>
<summary><b>3. Cloud-Based Self-Healing Infrastructure Monitoring System</b></summary>

<br />

* **Business Problem:** Manual infrastructure failure interventions led to unpredictable downtime and delayed incident logging during EC2 host outages.
* **Technical Approach:** Configured AWS CloudWatch Alarms to monitor EC2 CPU and health metrics. Triggered AWS Lambda functions to log event audits into Amazon DynamoDB while SNS notified sysadmins and EC2 Auto Scaling replaced failed instances.
* **Key Outcome:** Achieved zero-downtime automated recovery and automated audit trail generation.
* **GitHub Repository:** [Cloud Self-Healing System](https://github.com/piyushi-singhal/Cloud-Based-Self-Healing-Infrastructure-Monitoring-System)

</details>

<details>
<summary><b>4. FixForsight — Predictive Maintenance & AI Security Platform</b></summary>

<br />

* **Business Problem:** Industrial hardware operators required automated anomaly detection to prevent catastrophic equipment failure.
* **Technical Approach:** Preprocessed industrial sensor logs, engineered 18+ operational health features, and benchmarked XGBoost and Random Forest classifiers.
* **Key Outcome:** Achieved **98.15% classification accuracy** and **0.97 ROC-AUC** for failure risk forecasting.
* **GitHub Repository:** [QuantEdge / FixForsight](https://github.com/piyushi-singhal/QuantEdge)

</details>
